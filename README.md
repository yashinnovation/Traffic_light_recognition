# Traffic Light Recognition System 🚦

This project is an AI-based Traffic Light Recognition System developed using Computer Vision and Deep Learning techniques. The model is capable of detecting and classifying traffic light signals into different categories such as Red, Yellow, and Green in real time. The system uses image processing and object detection algorithms to improve recognition accuracy under various lighting and environmental conditions.

The project is designed to support applications related to autonomous vehicles, smart traffic management, and driver assistance systems. It can process both images and live video streams using a webcam for real-time detection. This project demonstrates the practical implementation of machine learning, OpenCV, and deep learning frameworks in solving real-world transportation problems.
